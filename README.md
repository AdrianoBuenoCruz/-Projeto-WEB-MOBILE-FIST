# Horta Municipal

Sistema Web para gestão de hortas comunitárias desenvolvido como projeto acadêmico.

## Funcionalidades

- Cadastro de usuários
- Controle de canteiros
- Gerenciamento de cultivos
- Controle de colheitas
- Interface responsiva
- Instalação como PWA (Progressive Web App)

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PWA (Manifest + Service Worker)
